# Uncertain checkout quote release

A release request can succeed on the server even when its response is lost or a proxy returns a server error. Previously the checkout displayed the old reservation and a generic error as if the old status were current. The panel now treats network errors, 5xx responses, and a 2xx response without a matching, structurally usable closed quote as an uncertain release. It explains that stock may still be held or may have been released; labels the displayed quote as last known, hides the live hold countdown and definitive stock claims, and offers a full checkout reload. It warns that an earlier request may still finish after a reload. Release and new reservation actions are blocked in the mounted panel until reload; no automatic retries occur. Explicit 4xx rejections remain distinguishable from unknown outcomes. The successful-release response check covers the quote identity, state, version and fields used by the UI; it is not general-purpose validation of all checkout endpoints.

Local results: 623 unit/component tests, typecheck and isolated production web build passed. Component tests cover network and server errors, malformed success responses, mismatched or still-reserved quotes, an explicit rejection, disabled actions, preserved focus and a later prop refresh. At 320, 390 and 1440 CSS pixels, Chromium with synthetic cart/quote data and an intercepted 503 verified keyboard focus, no duplicate release, last-known status, reload navigation, selected Axe checks and document overflow. No real cart, checkout service or identity provider was exercised.

This is an in-memory UX guard: reloads or other tabs do not preserve the warning, and reloading cannot prove a delayed request has completed. It does not add durable command tracking, guarantee stock state, implement payment or order placement, or establish production readiness. Existing reservation-create and quote-read response validation need separate review. No Supabase connection, user database change or deployment was performed.
