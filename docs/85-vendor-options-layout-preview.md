# Vendor option layout preview

The product layout preview now links to a separate responsive, transient option layout. It supports adding and removing up to eight **preview-only** options, local option name/SKU/positive minor-unit price/currency inputs, inline malformed-input feedback, and a summary reflecting only what the viewer entered. It uses no default currency or fabricated product/price. The UI limit is explicitly a preview limit, not a catalog policy; the market currency, SKU uniqueness and option structure are not verified. The UI does not represent its values as a real listing or price, and does not submit, persist, upload photos, adjust stock or publish. No store data is fetched and the page does not grant vendor access.

A production workflow still needs authorized store selection, real product/variant mutations, server-side validations, error/version handling, image review, inventory and moderation integration. Browser/device visual and assistive-technology review remain open; jsdom tests cover temporary interactions, input validity, clear non-submission boundaries and the local limit. This design is an interpretation; the supplied vendor reference has no dedicated option-editor screenshot. No database or deployment configuration was changed.
