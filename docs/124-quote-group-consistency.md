# Quote item and store-group consistency

A quote could previously have line totals matching its subtotal while omitting the line's store group. The price summary only compared groups that were present, so an incomplete list could appear trustworthy. Duplicate line, variant or group identities and empty quotes had similar ambiguity.

The shared quote summary now flags missing or unused groups, duplicate group/store/item/variant identifiers (including UUID case differences), blank identifiers and empty quotes. Each item must belong to a represented group, each group must have a line, and duplicate identities are rejected for price presentation. When structure is ambiguous, the summary returns no subtotal and checkout marks both subtotal and line amounts unavailable, with an accessible warning. This is a presentation warning rather than rejecting the whole quote: a RESERVED quote still offers release. Duplicate line IDs also get stable distinct rendering keys so they do not cause React key collisions.

Verification: 751 unit/component tests passed before one additional duplicate-line UI regression was added; the updated focused quote/UI tests and typecheck passed, and an isolated production web build passed. Coverage includes multi-store and case-equivalent valid groups, zero-priced unused groups, duplicates, blank IDs, empty data, and release availability. Chromium at 320, 390 and 1440 CSS pixels used a synthetic API and local BFF to load an orphaned line whose numeric subtotal otherwise matched, verify the warning and withheld prices, then release the reservation with keyboard focus recovery. Selected Axe and overflow checks passed, including a long unbroken product title. This synthetic fixture is not a real checkout or identity service.

These checks do not prove quote ownership, complete inventory, current price or full backend integrity; a valid-looking but incomplete set of items cannot always be detected without authoritative reconciliation. The in-memory recovery limitations remain. Real-service end-to-end, cross-tab and full screen-reader/device testing are outstanding. No Supabase connection, user database change or production deployment was performed.
