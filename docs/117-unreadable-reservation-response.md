# Unreadable reservation success response

A 2xx reservation response previously caused the client to discard its attempt ID and assume the returned JSON was a usable quote. Malformed JSON, a missing quote, wrong cart or city, an unknown state or malformed rendered fields could instead cause a broken checkout or encourage a new attempt even though stock may already be held.

The panel now checks the mutation response's supported state and renderable fields, and compares its cart and destination against those captured when the original attempt began. If the response cannot be trusted, the UI reports an unknown reservation outcome, keeps the selected city locked and retains the same attempt ID, cart identity, destination and cart version in memory. An explicit retry sends the identical original request payload; it does not automatically retry. A valid replay can report a closed quote, since the server's idempotency lookup may return an earlier attempt that has since been released or expired. The cart identity used for validation is captured with the attempt and is not added to the browser's request body.

Local verification: 632 unit/component tests, typecheck and an isolated production web build passed. Component tests cover invalid JSON, null or incomplete success, wrong cart/city, unknown state, invalid item/version, subsequent prop changes, unchanged retry payload and valid replay of a closed quote. Chromium at 320, 390 and 1440 CSS pixels used synthetic checkout data and intercepted malformed 2xx responses to check uncertain messaging, focus, duplicate suppression, same-payload retry, release, selected Axe scans and overflow. No real identity or checkout service was used.

This validates mutation responses adopted by the panel, not all server-rendered quote reads, service data or authorization. An in-memory attempt is lost on reload or in another tab; reloading cannot establish that a delayed request finished. It is not durable cross-tab idempotency, payment, order placement or full production readiness. No Supabase connection, user database change or deployment was performed.
