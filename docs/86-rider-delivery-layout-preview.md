# Rider delivery layout preview

The rider workspace now links to a public, data-free design preview of offer, pickup/route and delivery-proof layouts, informed by the rider reference and UI-R05–R06/R11. Viewers can switch preview states. All operational buttons and the verification-code field are disabled; no real rider profile, assignment, offer, timer, route, address, customer, location, OTP or earnings data is read, requested, shown or changed. There are no invented names, amounts, maps or timing claims. It is not authorization or a delivery tool.

Real operations remain unconnected. Authorized rider scope, consented shifts/location, server-derived offer expiry, stale-offer handling, pickup, recipient OTP security, completion/COD and error recovery must be implemented and independently verified before use. DOM tests check the preview boundary and disabled controls. A limited headless-browser and automated accessibility audit is recorded in `docs/88-ui-browser-audit.md`; it does not cover real devices, screen readers or backend behavior. The provided reference is a dashboard, not a dedicated flow mockup; this interpretation needs visual review. No database or production deployment was changed.
