# Product photo gallery

Product detail now uses a responsive, keyboard-operable gallery for the catalog's supplied image metadata. It shows the first photo initially and lets the buyer select any returned photo, with descriptive button labels, pressed state and a text position indicator. An empty image list and a failed image load are explicitly shown; selecting another photo remains possible. There are no fabricated photos or automatic slides. Images remain same-origin through the existing UUID-validated public image proxy; no API URL or arbitrary external image URL is passed to the browser. The backend's approval/public eligibility requirements are unchanged. The backend currently permits up to eight product images; the gallery does not silently omit later images.

DOM interaction tests cover selection, missing and failed images, changed image data, the eighth image and encoded proxy paths; server-rendered page tests check integration. Tests use synthetic metadata and do not verify real-browser keyboard behavior, image loading through a configured backend, assistive technology or visual fidelity. The current Vercel preview has no configured market/catalog, so the populated gallery cannot be reviewed there yet. No database or production configuration was changed.
